# Network Scanner

Автономный сетевой сканер безопасности на базе одноплатного компьютера Raspberry Pi.

Дипломный проект по теме: **«Разработка автономного сетевого сканера на базе одноплатного компьютера для аудита информационной безопасности»**

## О проекте

Устройство сканирует локальную сеть, выявляет устройства, открытые порты и оценивает риск безопасности. Работает автономно без ПК, показывает статус на встроенном LCD-экране, предоставляет веб-интерфейс для управления и отправляет отчёты на центральный сервер через Wi-Fi.

## Возможности

- 🔍 **Сканирование сети** — обнаружение устройств через Nmap
- 🚦 **Оценка риска** — Низкий / Средний / Высокий
- 🌐 **Веб-интерфейс** — дашборд с автообновлением (порт 8080)
- 📱 **QR-код** — быстрый доступ с телефона
- 🔎 **Поиск и фильтры** — по IP, имени, риску
- 📥 **Экспорт CSV** — отчёт для анализа
- 📊 **История сканирований** — последние 20 записей
- 🖥️ **LCD-экран** — статус, IP, температура, RAM
- 📡 **Клиент-сервер** — отправка отчётов на центральный сервер (порт 9090)
- ⏰ **Автосканирование** — каждые 15 минут
- 🔐 **API-ключ** — защита критичных эндпоинтов
- 🚀 **systemd-сервисы** — автозапуск при включении


## Стек технологий

- **Go 1.21** — backend, REST API
- **Nmap** — сканирование портов
- **`go:embed`** — встраивание статики
- **systemd** — автозапуск сервисов
- **Raspberry Pi OS (Bookworm)** — операционная система
- **HTML/CSS/JS** — веб-интерфейс
- **Python (evdev)** — чтение тачскрина
- **Bash** — скрипты отображения

## API эндпоинты

### Публичные

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Веб-интерфейс |
| GET | `/api/health` | Health check |
| GET | `/api/version` | Версия сервиса |
| GET | `/api/results` | Текущие результаты сканирования |
| GET | `/api/system` | Системная информация |
| GET | `/api/qr` | QR-код PNG |
| GET | `/api/export.csv` | Экспорт отчёта в CSV |
| GET | `/api/device/{ip}` | Устройство по IP |
| GET | `/api/devices?risk=high&has_ports=true` | Фильтрация устройств |
| GET | `/api/stats` | Агрегированная статистика |

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/scan` | Запуск сканирования |
| GET | `/api/reports` | История отчётов |
| DELETE | `/api/reports` | Очистка истории |

## Быстрый старт

### Требования

- Raspberry Pi 3 Model B (или новее)
- Raspberry Pi OS Bookworm (Legacy, 32-bit)
- Go 1.21+
- Nmap
- qrencode

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/USERNAME/network-scanner.git
cd network-scanner

# Собрать веб-сервер
cd web
go build -o scanner-web server.go

# Собрать центральный сервер
cd ../server
go build -o scanner-server server.go

# Запустить через systemd
sudo cp ../systemd/*.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now scanner-web scanner-server

#Проверка

# Health check
curl http://localhost:8080/api/health

# Запустить сканирование (с API-ключом)
curl -H "X-API-Key: scanner-secret-key-2026" http://localhost:8080/api/scan

#Тесты

cd web go test -v
